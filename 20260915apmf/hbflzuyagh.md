# 试管婴儿预产期是怎么计算的

> 更新时间：2026-09-15 (UTC+8)

试管婴儿预产期是怎么计算的?做试管婴儿验孕后是会给家庭带来无比喜悦的。怀孕后也有很多准父母会很困惑，做试管婴儿预产期怎么算呢?今天就让齐康喜孕多试管婴儿医疗服务顾问来和大家讲一讲。试管婴儿的预产期到底怎么算。

一般来说对于月经周期稳定在28天的女性，一般使用以下的公式来推算预产期：

末次月经开始的第一天所在的月份加9或减3，为预产期月份数;天数加7，为预产期的日期。如末次月经是2021年1月1日，月份1+9 ，日期1+7 ，预产期即为2021年10月8日;如果末次月经是2021年5月12日 ，月份5-3， 日期12+7 ，预产期即为2021年2月19日。

接受试管婴儿的患者进行了促排卵治疗，以及移植周期，药物可能会影响月经周期，那么用末次月经来计算预产期可能会有些出入。那我们也可以用移植胚胎的日期来计算预产期，这样更准确一些，一般来说是移植第五天的囊胚，那么就把移植日向前推19天，把这个日子作为末次月经的第一天，然后月份加9或者减3，天数加7。

比如，在2021年5月20日移植囊胚，向前推19天是5月1日，月份5+9为明年2月，日期1+7是8，那么预产期为2021年2月8号。

准妈妈们也可通过孕期产检医做B超时测得胎头双顶间径、头臀长度及股骨长度即可估算出预产期。

预产期不是精确的分娩日期，可以提醒你胎儿安全出的时间范围，所以不要把预产期这一天看得那么精确。到了孕37周应随时做好分娩的准备，但不要过于焦虑，听其自然，如到了孕41周还没有分娩征兆出现，有条件的应住院观察或适时引产。

在预产期前后两周内分娩，都属正常。如在怀孕24～36周间出则视为早产，如果孕妇已经过了预产期，还没出现分娩征兆，需要注意以下几点：

1. 不要过于紧张，即使孕周准确，预产期后两周内分娩时母婴的影响也不大，但要注意胎动情况。胎动监护是妊娠晚期最好的自我监护手段，能反应宫内胎儿存状况，一旦胎动每小时少于3次或在12小时内少于20次或胎动减弱，则需马上到医院作进一步检查，医会根据情况决定分娩时机。

2. 继续进行产检，并把孕早期的检查(如B超、验血、妊娠试验等)结果及胎动出现的时间、结果告诉医，让医给你再次核对孕周。

3. 加强产前检查，缩短检查间隔时间，随时与医取得联系，告知宫内胎动情况，同时B超随访羊水量。如果无异常，可在密切监护下继续妊娠

4. 如果达到临床所谓过期妊娠时，由于部分孕妇的胎盘会出现老化、胎儿会出现缺氧窒息，所以对孩子的危害较大，应及时到医院采取措施。
