# 孕期便秘？别急，这些小妙招轻松解决！

> 更新时间：2026-09-11 (UTC+8)

“便秘”是孕期常见问题之一，在每个妊娠阶段及产后6-12周，其患病率约为16%-39%。

相当于，每5人中，至少有1位孕妈妈存在便秘的困扰。

**妊娠期出现便秘的原因**

1.激素水平的变化：女性怀孕后胎盘会分泌大量的孕激素，在孕激素的影响下，胃肠道平滑肌的张力较孕前减弱，引起便秘。

2. 钙、铁等元素的影响：孕期妇女都会补充适量的钙、铁等元素，但是在补充铁剂容易使结肠充血；补充钙片容易与肠道的食物残渣结合成不溶解的较硬的物质，使大便干结。

3.机械行压迫：女性怀孕后子宫逐渐增大，不断压迫共处于盆腔中的直肠（尤其是孕晚期），使粪便排出的阻力增加。

4.腹压不足：女性怀孕后胎儿不断生长，孕妇的腹壁肌肉越来越薄弱，排便时没有足够的腹压推动。因此，即使有了便意，堆积在直肠里的粪便仍很难排出去。

5.活动减少：女性怀孕后往往担心过分活动会损伤胎气，活动量较孕前明显减少，导致使得胃肠蠕动进一步减少，加重腹胀和便秘的发生。

6. 精神压力：女性怀孕后往往受到亲人的格外关照，孕妇精神心理压力也是导致便秘发生的原因之一。

**中医怎么看待妊娠期便秘？**

《诸病源候论》云：“妊娠大便不通候：三焦五脏不调和，冷热痞结，津液竭燥，肠胃痞涩，蕴积结于肠间，则大便不通。”

中医认为，妊娠期气血聚于胞宫养胎，孕妇会出现气虚、血少、津亏等情况，不能生津濡养肠胃，导致肠道干燥，大便积结，出现排便困难。

**预防便秘的方法来咯**

**孕妈妈们做好笔记！**

1.培养良好的排便习惯：每日“定时”排便，排便时集中注意力，不做阅报或阅览电子产品等分散注意力的事情。

2.保持愉悦的心情：孕期保持愉悦的心情，回避不良的精神刺激，有利于维持肠道的通畅。    

3.调整好饮食：怀孕期间进食不必过于精细，可适当加入粗粮，多吃新鲜蔬果，摄入充足的水分，可增加胃肠的蠕动。

4. 适当的运动：怀孕期间孕妇可以在身体允许的情况下，根据个人喜好选择适当运动（如游泳、散步、瑜伽等）使腹肌收缩力增强，使排便更有动力。但需要注意的是，要避免剧烈的运动，避免揉腹按摩等刺激腹部的手法。

5. 保证规律的作息时间：充足的睡眠以及规律的作息时间可以使孕妇心情愉悦，能够更好的维持排便规律。

**孕期便秘的中医小妙招**

中医学认为便秘是由大肠的传导功能失司导致的，病机不外乎虚、实两大类。妇女怀孕属于特殊阶段，用药时要谨慎小心，中医治疗相对安全，快来试试下面的小妙招吧。

**1.耳穴压丸**

耳穴选取大肠、小肠、脾、胃，找到上述穴位后，可以在局部贴上耳豆再稍加力按压，以局部酸、胀、痛、热为主。每日按压3次，每次按压2-3分钟。耳穴压丸能起到调和气血，疏通经脉的作用，可辅助改善孕妇便秘。

**2.点按支沟穴、足三里**

操作方法：找到穴位后，拇指指端置于穴位处、其余四指放在穴位对面，用力点按1-2分钟，以局部酸胀或酸痛为度，休息片刻后重复3次。每日按压3次。

（1） 支沟属于手少阳三焦经腧穴，位于：前臂背侧，在阳池穴与肘尖的连线上，腕背横纹上3寸。点按支沟穴可以起到开郁行气、通腑泻热的作用。

（2）足三里属于足阳明胃经腧穴，位于：位于小腿前外侧，犊鼻穴下3寸（4横指），距胫骨前嵴一横指处。点按足三里可以起到调节机体免疫力、调理脾胃、通经活络、的作用。
