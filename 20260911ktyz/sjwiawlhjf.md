# 对口帮扶出新招，远程MDT研讨推动肿瘤技术发展

> 更新时间：2026-09-11 (UTC+8)

为扎实开展“六个年”活动，学习北京大学深圳医院先进的MDT诊疗模式以及先进的肿瘤诊疗经验及技术，提升医院救治癌症患者的综合能力，5月15日下午，百色市人民医院在门诊楼8楼远程医学中心，利用远程医学系统同步举办“2019年北京大学深圳医院与百色市人民医院脑转移癌联合MDT研讨会”。

▲会议现场

北京大学深圳医院院长陈芸、党委书记王涛、副院长王琦，百色市人民医院院长李廷阳等领导到现场指导，北京大学深圳医院肿瘤科王树滨主任、神经外科陈保东主任、放射治疗科刘雅洁主任、百色市人民医院肿瘤放疗科蒙以良主任担任会议主席；北京大学深圳医院神经肿瘤MDT团队、中山大学肿瘤医院陈丽昆教授MDT团队，百色市人民医院神经外科陆万流主任、神经内科李绍发主任、心胸外科郑发德主任、影像科黄筠洋主任、核医学科梁绍奖主任、病理科卢运龙主任、肿瘤化疗科陈坚贤主任、营养科岑凤珠主任、肿瘤放疗科郑学嵩主治医师、腺体外科覃仕欢主治医师等科室专家参加研讨会。

▲会议现场

百色市人民医院是北京大学深圳医院对口帮扶单位，本次会议是百色市人民医院第一次运用远程医学系统与北京大学深圳医院进行MDT研讨，使相隔千里的深圳和百色两地的神经肿瘤MDT团队，通过大屏幕实时同步直播，面对面进行肺癌、乳腺癌、恶性黑色素瘤等脑转移癌的多学科研讨及经验交流，成为百色市人民医院和北京大学深圳医院多学科诊疗的一种新的模式。通过远程同步视频直播的新模式，增进两家医院MDT团队间的交流，为百色市人民医院搭建了一个与国内顶尖专家沟通交流的平台。会上，三家医院的专家就肺癌、乳腺癌、恶性黑色素瘤等脑转移癌病例进行讨论，从患者病理、影像、核医学等方面进行分析，充分研讨如何选择治疗方法，如手术、放疗、药物治疗（化疗、靶向治疗、免疫治疗）以及营养支持等，让百色市人民医院专家学习到了最新、最权威的肿瘤治疗方法，提高百色市人民医院的肿瘤诊疗水平，为百色及周边滇黔桂地区患者谋福利。

▲与会人员进行讨论

大会主席王树滨主任表示，在两院领导的大力支持下，本次两省三地神经肿瘤MDT团队经过4个小时的多学科研讨，取得了很好的效果，交流了经验，增进了感情，希望MDT团队能坚持下去，不仅要线上交流，也期待来回两地线下互动交流，更好地为病人解决问题。

陈芸院长在会上指出，作为远程的重要项目之一，希望能够在百色市人民医院搭建5G基站，两家医院信息技术部门搭建好远程会诊平台，做好远程MDT研讨会的硬件和技术支撑工作，点对点远程视频会议中心做到速度更快、图像更清晰；希望两家医院肿瘤MDT团队努力把远程MDT研讨会纵深开展下去，实现常态化与制度化，可持续发展；两地MDT团队互相分享、互相交流、互相提升，最终让患者受益。她希望两院远程MDT研讨，路越走越宽，越办越好。

▲蒙以良主任主持会议

会后，蒙以良主任表示，本次研讨会是两院MDT团队首次开展的一种新型学术交流活动，通过远程同步举行两地的多学科研讨，不出家门就可以同北京大学深圳医院的专家教授们进行面对面的交流，学习到北大深圳医院先进的多学科诊疗模式以及肿瘤相关疾病诊疗流程和治疗方案，进一步提升了百色市人民医院的肿瘤诊疗水平，提高了百色市人民医院肿瘤MDT团队的综合实力，最终到达我们的初衷，让患者更加受益。

李廷阳院长强调，百色市人民医院要依托北京大学深圳医院21个MDT团队，借鉴北京大学深圳医院先进的多学科诊疗模式，走出去，请进来，远程线上，来回两地线下现场交流，努力建设好百色市人民医院相关MDT团队，做到常态化、制度化可持续发展。
